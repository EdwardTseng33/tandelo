# 試點準備包（W1–2）

策略 2.1 第 06 章的 W1–2「問、簽、備、分組」要用到的東西，全部在這個資料夾。數字與門檻以策略頁為準；這裡只放可以直接拿去用的腳本、表單與規格。

| 檔案 | 用途 | 誰用 |
|---|---|---|
| `interview-kids.md` | 20 位國二國三孩子試玩 Demo 的腳本（30 分鐘） | 城堡、嚮導 |
| `interview-parents.md` | 30 組家長訪談腳本（40 分鐘），含願付與分層選擇 | 城堡、客戶成功 |
| `consent-draft.md` | 家長同意書草案（個資告知、13 歲以下同意、保留與刪除、錄音與 AI 標示）；上線前法務對照原文 | 法務、客戶成功 |
| `intervention-log.md` | 人工介入紀錄表：欄位、觸發原因、填寫規則；對應後端 `/interventions` | 嚮導、巡查員、客戶成功 |
| `pre-post-test-spec.md` | 獨立題本（前測、後測）規格：與日常練習分離、缺測計入分母 | 內容團隊 |
| `layer-assignment.md` | 四層分組規則與每層最低人數、招不滿的降級順序 | 城堡 |
