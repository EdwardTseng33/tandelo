# 人工介入紀錄表（POC 人力介入階梯實驗的核心紀錄）

每一次真人為某個孩子或小隊做的事都要記，當天記。這份紀錄決定「人力在哪介入最划算」，也是避免把人做的算成系統做的唯一證據。對應後端 `POST /interventions`。

## 欄位
| 欄位 | 值 | 說明 |
|---|---|---|
| 時間 | 日期時間 | 介入發生的時間，不是填表時間 |
| 誰做的（by） | system／patrol／guide／cs | 系統自動（預錄講解、換變體）也要記，才能比 |
| 對誰 | 學生暱稱或小隊名 | 不寫真名 |
| 層 | L0／L1／L2／L3 | 由小隊的分層帶出 |
| 類型（kind） | nudge 催促／explain 解惑／comfort 安撫／demo 示範／review 審核／parent_note 給家長的一句 | 一次一種，混合就拆兩筆 |
| 觸發（trigger） | help_timeout 求援 30 分鐘沒人回／three_wrong 同怪連錯三次／three_days_off 三天沒開／expedition 遠征／weekly 每週固定／parent_message 家長來訊／manual 自己判斷 | manual 要在備註寫原因 |
| 分鐘 | 小數 | 實際花的時間，含準備 |
| 備註 | ≤ 200 字 | 不放個資；寫「做了什麼、孩子的反應」 |

## 填寫規則
- 系統先試過才輪到人：求援先播預錄講解，30 分鐘後才升給巡查員；巡查員解不了才到嚮導。每一次升級都是一筆。
- L0 的孩子理論上沒有真人介入；若有（例如家長來訊），照記，這是 L0 的「漏」。
- 嚮導每週每隊審核上限 20 分鐘、巡查員每週每生上限 5 分鐘；超過也要記，超過代表流程要改，不是人不夠努力。
- 每週日客戶成功彙總：每層每生每週人力分鐘、各類型分鐘、各觸發次數，對照該層的練習天數與再測完成率。

## 結案要回答的
每一層的「成效除以人力分鐘」：成效＝再測通過數與前後測進步；分鐘＝這張表加總。找出比值最高的一層，定為主力營運模型。
