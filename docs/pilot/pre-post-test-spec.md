# 獨立題本規格（前測、後測）

目的：證明學習改善，不靠日常練習的答對率。題本與日常練習、再測完全分離，孩子在試點前後各做一次。

- **範圍**：數學八隻怪對應的八個卡點，每個卡點 3 題（一題基本、一題換情境、一題綜合），共 24 題，40 分鐘內完成。
- **出題**：由變體引擎用獨立種子產生，再經內容老師審；前測與後測題目不同、難度對等（同一產生器、同一難度、不同種子）。
- **施測**：線上、不給提示、不能求援、AI 關閉；計時但不顯示倒數；可中途儲存一次。
- **缺測**：沒做後測的孩子計入分母，以「未改善」處理；報表另列缺測率。
- **記分**：每題對錯、所踩的錯法（trap）、作答時間；報告分「通過的卡點數」「仍踩同一錯法的卡點數」「改善的卡點數」。
- **分層比較**：四層各自的前後測差，附人數與人工介入分鐘；不做跨層的顯著性宣稱（樣本小），只做方向判讀。
- **給家長**：後測結果寫進最後一封週報，用「通過了什麼、還在補什麼」的語言，不給排名。
