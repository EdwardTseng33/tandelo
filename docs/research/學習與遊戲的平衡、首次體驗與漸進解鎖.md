# 學習與遊戲的平衡、首次體驗與漸進解鎖（2026-10）

兩個問題：Top players 怎麼在學習與遊戲之間取平衡？第一次打開的認知負擔要怎麼降？以下整理研究結果與我們的量測。標 ◇ 的來源被網路代理擋住，內容取自搜尋摘要，未打開原文核對。

## 一、遊戲獎勵掛在什麼行為上

| 產品 | 遊戲機制 | 獎勵掛在 | 證據或爭議 |
|---|---|---|---|
| Duolingo | XP、連勝、10 級週聯賽、任務 | 完成課數 | 官方說聯賽讓學習時間 +17%◇；質性研究發現使用者為了 XP 刷簡單課 |
| Prodigy | RPG 對戰、寵物、裝備、付費會員 | 答題量 | 使用量與州考進步正相關；22 個團體向 FTC 投訴：19 分鐘 16 則會員廣告、只有 4 題數學 |
| Khan Academy（新版） | 精熟等級、技能點換 Level、週連勝、Gems 換配件、Gem Jam 小隊賽 | 精熟 | 官方承認舊版能量點數「只量努力、不量精熟」◇，改成精熟才給點 |
| IXL | SmartScore 0–100、獎章 | 精熟分數 | 90 分後答錯扣很多，學生急著補分、焦慮 |
| Brilliant | XP、連勝、30 人聯賽 | 活動量 | 查不到成效研究 |
| DragonBox | 謎題本身就是代數，圖案逐步換成符號 | 過關＝解題 | 有 RCT 正向，也有研究 3.5 小時後沒進步 |
| Blooket／Gimkit | 迷你遊戲、代幣、商店、抽卡、偷金幣 | 答對題 | 隨機事件讓全答對的人也可能輸；遊戲蓋過學習 |
| Classcraft | XP、HP、職業、小隊互救 | 老師依行為給分 | 2024/6/30 關站 |
| PaGamO（台灣） | 答題攻佔領土、金幣、寶物 | 答對題 | 創辦方說約 80% 時間在答題◇；查不到獨立研究 |
| 均一（台灣） | 能量點數換頭像、徽章、精熟 | 看影片與答題；部分徽章掛精熟 | 查不到成效研究 |

研究結論：

- Deci、Koestner、Ryan（1999）統合 128 個實驗：可預期、有形、做完就給的獎勵會削弱內在動機，對兒童更明顯。
- Sailer 與 Homner（2020）統合分析：遊戲化對認知、動機、行為有小到中等的正效果，只有認知效果在嚴謹研究中穩定。
- Hanus 與 Fox（2015）：有排行榜加徽章的那組，內在動機與期末成績都較低。

三種平衡模式：

- **遊戲包裹練習量**（Prodigy、Blooket、Gimkit、PaGamO、Duolingo 的 XP）：黏著高、上手快；孩子會刷量、重速度，容易引出付費與比較。
- **遊戲獎勵精熟**（Khan 新版、IXL、均一的精熟徽章）：獎勵等於真的學會、跟段考一致；容易卡關挫折，精熟判定要準。
- **遊戲就是學習本體**（DragonBox、Minecraft）：內在動機強；做起來貴，轉移到考試的證據不一。

Tandelo 屬於第二種，加上外觀與身分層。Khan 正從第一種轉向第二種，方向一致。

## 二、首次體驗與解鎖節奏

- Duolingo：先上一課再註冊，30 秒內在答第一題；完成 10 課才進聯賽；首頁是一條路。
- Prodigy：教學關打完才能自由走動；打贏第一場才選寵物；地圖靠等級開。
- Khan Academy Kids：首頁基本上只有一顆大 Play。
- Headspace：先問幾題、只推一門課後，開始上課比例從約 31% 變約 63%。Calm：首頁一顆播放鍵。
- 手遊：Pokémon GO Lv5 開道館、Lv10 開交換與對戰聯盟；原神 AR12 開每日委託、AR20 開深境螺旋。
- NN/g：讀過教學和跳過教學的人任務成功率 91% 對 94%，用到時再提示比事前教學有效；工作記憶大約 4 塊（Cowan）。

## 四、做進 Demo 0.7 的決定

- **漸進解鎖**：第 1 天只有「今天」「我」兩個分頁，首頁四樣：林老師一句話、今天 3 題、三顆進度點、小隊。第 1 週末多「這週」。第 3 週才出現林老師的信、怪回來了、地圖、出題戰、公會、職位與稱號。
- **分頁 5 個改 3 個**：今天、這週、我。地圖、出題戰、公會收進「這週」。
- **白話**：巡邏改「今天 3 題」、Boss 接力改「接力題」、伏擊與叫醒在首頁合成「怪回來了」、副本改「這週」、嚮導在首頁改「林老師」；整備條移出首頁；公會改名「林間公會」，不再跟營地來信撞名。
- **題目頁**：小陪收成一顆「卡住了？問小陪」，答錯或按了才展開；進度顯示「第 N / 3 題」；狀態列的示範時鐘不再能點。
- **示範切換**：首頁底部與示範面板可以切第 1 天、第 1 週末、第 3 週，每一段載入對應的世界狀態。
