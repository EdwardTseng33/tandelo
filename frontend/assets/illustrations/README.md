# Tandelo 向量插圖

19 張手寫 SVG（清單 18 項，第 18 項含商標與字標兩檔），每張另有一個 `-dark` 深色版，共 38 檔。
全部延伸同一個母題：**兩個重疊的圓，重疊處就是學會發生的地方**。

## 規範（每一檔都符合）

- 幾何、平面、留白多；沒有漸層、沒有陰影、沒有濾鏡。
- 人物是一顆頭加圓肩，沒有五官。
- 線條一律 1.9px 圓頭（`vector-effect: non-scaling-stroke`，放大縮小都維持 1.9px）。
- 數學式是手寫感線條，不是字體；圖裡沒有任何 `<text>`，不需要載入字體。
- 沒有 `<script>`、沒有 `<image>`、沒有外部連結；`viewBox` 固定；最大一檔約 12KB。
- 顏色只用品牌色票；不用純黑、不用紅色代表「錯」。LINE 綠只出現在 `step-parent`。
- 重疊色用兩色相乘的結果：淺色版 `#0D281B`（與網站商標一致），深色版 `#1D3B28`。

## 深色與淺色

| 檔名 | 用在 | 差別 |
|---|---|---|
| `名稱.svg` | 燕麥底 `#F6F4EE`、白卡 | 卡片白、線條墨綠 |
| `名稱-dark.svg` | 深色底 `#0C1412`、卡 `#131D1A` | 卡片轉暗、字轉亮、松綠改用較亮的 `#1F8C78`；珊瑚與金不變 |

教室白板在深色版仍是淺底（規範：上課時白板永遠是淺底）。
`pain-alone` 本身就是夜景，兩版只有外框深淺不同。

網站的用法：`<img data-ill="名稱" src="assets/illustrations/名稱.svg" alt="">`，
`assets/site.js` 會依目前的深淺色（含手動切換與 22:30 自動轉暗）把 `src` 換成 `-dark` 版。
沒有 JavaScript 時固定顯示淺色版。

## 給動畫用的 id

- `celebrate-dots`：每顆圓點是獨立的 `<circle id="dot-1">`…`<circle id="dot-24">`，中心的兩個圓是 `<g id="core">`。
- `coach-states`：四態各一組 `<g id="idle">`、`<g id="listening">`、`<g id="talking">`、`<g id="celebrate">`。
- `hero-tandem`：`<g id="duo">`、`<g id="mates">`、`<g id="gold-card">`。
- `logo-wordmark-outline`：`<g id="mark">`、`<g id="wordmark">`。

## 已知限制

- 字標是用圓與直線構成的幾何粗體，神似品牌字 Outfit 700，但不是從字型檔轉出的輪廓；
  正式印刷品請改用字型檔轉外框的版本。
- 圖裡不放文字，所以 `step-parent` 的「今晚可以問他」是用引號加橫條表示，需要文字時由頁面疊上。
- 以 `<img>` 載入時不會跟著系統深淺色自動換色，要用 `-dark` 檔（網站已由 `site.js` 處理）。

## 重新產生

`_src/` 是產生這批檔案的原始碼（Python 3，無第三方套件）：座標與構圖都寫在 `a.py`、`b.py`，
色票與共用圖形在 `lib.py`。改完後執行：

```
cd assets/illustrations/_src && python3 gen.py ..
```
