# Tandelo（概念驗證）

對準段考的 8 週小隊課：孩子卡在哪，就從哪裡開始。

這是一個**概念驗證（POC）**：品牌網站、老師招募頁，以及一個可操作的 App 原型（學生、家長 LINE、老師三條流程）。純靜態網頁，沒有後端；所有示範資料都是虛構的，表單不會送出，資料只留在使用者自己的裝置。

- 網站：`index.html`（產品介紹）、`teachers.html`（老師招募，含收入試算器）
- App POC：`app/`（原生 ES modules，手機優先；桌機顯示手機框與說明面板）
- 共用樣式：`assets/brand.css`

## 本機預覽

任何靜態伺服器都可以，例如：

```bash
npx serve .
```

## 說明

- AI 教練「小陪」在 POC 中以前端規則與預寫對話模擬，畫面標示「示範模式」。
- 全站 `noindex`，不供搜尋引擎收錄。
- 授權：保留所有權利（POC 展示用）。
